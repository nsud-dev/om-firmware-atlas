# 0007 — Direct routes for owners and developers

The homepage keeps separate entry points. The owner finder and directory open the exact camera's showcase directly at the existing camera URL. Former showcase URLs forward to the camera with their project anchors intact. The fallback page links to the same project sections when JavaScript is unavailable. The camera page also keeps the former overview anchors.

A release's optional `installation` entry binds its guide to the camera and stock firmware. The owner page uses it to show the install action. A release without a matching entry links to its release notes. Test summaries draw from observations for the same camera, project and build label. Reports for other builds get a separate link and keep their original scope.

The developer landing page links to cameras, topics, reference, evidence and projects. Its recent findings come from dated evidence records. Per-camera research stays separate and links to the stock-firmware page for platform and built-in feature tables. The two camera views link directly to each other. Exact camera search results offer both routes and keep ambiguous model names distinct.

The records remain the shared source for both audiences and their agent routes. Validate route changes against the original OM-5 and Mark II, plus the E-M5 III display guide, in the desktop and mobile browser journeys.
