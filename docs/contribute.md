# Bring one useful source

You can contribute a repository, release, research finding, correction, community venue or camera test report. [Open an issue](https://github.com/xulfr/om-firmware-atlas/issues/new/choose), or prepare a PR using [CONTRIBUTING.md](../CONTRIBUTING.md).

## Ask an agent

Give an AI coding agent the [copyable source prompt](how-it-works.md#copyable-prompts). The entry route is [AGENTS.md](../AGENTS.md). Agents inspect relevant releases, branches and reports as well as READMEs. They reuse existing topics and records, preserve missing details and generate the human views in the same change. [How the Atlas works](how-it-works.md) follows a source all the way to publication.

## Report a camera result

Name the exact camera/generation, stock firmware, mod build and package digest if available. Describe what you did and what happened, including failures and recovery attempts. State what you did not check. Unknown details can remain unknown; do not fill them from what a release was expected to contain.

The repository owner reviews and merges; agents never approve or merge. The Atlas is a documentation home; implementation fixes belong with their upstream authors. [See the research starting guide](research.md) for choosing a contribution destination.
